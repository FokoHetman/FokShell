## The Idea

FokShell is a shell made to be extremely hackable using haskell alone.
In fact, *only* input handling is not meant to be a module.
That doesn't mean the shell is primitive though,
at the time of writing this, it provides most of the functionality one would expect
from a shell, such as Tab Completion, History, obviously the Prompt, etc.
Furthermore my goal is to make it provide a *lot* of Modules,
from language customization to all them visuals.
